# 🏠 Model House Configurator

Unity 기반의 **인터랙티브 모델하우스 컨피규레이터** 프로젝트입니다.

사용자가 1인칭 시점으로 모델하우스를 직접 탐색하면서  
각 공간의 정보를 확인하고, **바닥재·벽지·가구·커튼 등의 인테리어 옵션을 실시간으로 변경**할 수 있도록 구현했습니다.

---

## 📌 프로젝트 개요

- **프로젝트명** : Model House Configurator
- **개발 인원** : 2명
- **개발 엔진** : Unity 6.6 (6000.6.0f1)
- **렌더 파이프라인** : URP
- **협업 도구** : Git / GitHub
- **주요 목적**
  - 모델하우스 공간을 자유롭게 탐색
  - 공간별 정보 제공
  - 인테리어 옵션 실시간 변경
  - 선택한 옵션 요약 및 저장

---

## 🎯 주요 기능

### 🚶 1. 모델하우스 자유 탐색

- W / A / S / D를 이용한 1인칭 이동
- Shift를 이용한 빠른 이동
- 마우스를 이용한 시점 회전
- ESC를 이용한 UI 조작 모드 전환

사용자는 실제 모델하우스를 방문한 것처럼 공간 내부를 자유롭게 이동할 수 있습니다.

---

### 📍 2. 구역별 정보 안내

모델하우스의 각 구역에 진입하면 해당 공간의 정보가 자동으로 표시됩니다.

구성 공간:

- 현관
- 거실
- 주방
- 테라스
- 휴게실
- 서재
- 욕실
- 방

`ZoneTrigger`를 통해 플레이어의 구역 진입·이탈을 감지하고  
`ZoneData`에 저장된 공간 이름, 면적, 설명을 INFO 패널에 출력합니다.

---

### 🎨 3. 인테리어 재질 변경

옵션 패널을 통해 다양한 인테리어 재질을 실시간으로 변경할 수 있습니다.

#### 바닥재
- 원목
- 대리석
- 타일

#### 벽지
- 화이트
- 베이지
- 그레이

#### 커튼
- 다양한 색상 옵션

`MaterialSwapper`를 이용해 하나 이상의 Renderer에 원하는 Material을 적용합니다.

---

### 🛋️ 4. 가구 프리셋 변경

공간에 미리 배치된 여러 가구 조합 중 원하는 옵션을 선택할 수 있습니다.

주요 변경 대상:

- 소파
- 테이블
- 의자
- 공간별 가구 세트

각 가구 옵션은 `FurnitureSlot`에서 관리하며  
선택한 가구만 활성화하고 나머지 가구는 비활성화하는 방식으로 구현했습니다.

---

### 🗂️ 5. 옵션 탭 UI

컨피규레이터 패널은 기능별 탭으로 구성되어 있습니다.

- 바닥재
- 벽지
- 가구
- 커튼

탭을 선택하면 해당 옵션만 표시되며  
각 옵션 카드에는 이미지와 이름을 함께 제공하여 사용자가 쉽게 비교할 수 있도록 구성했습니다.

---

### 📋 6. 선택 옵션 요약

사용자가 선택한 인테리어 옵션을 한 화면에서 확인할 수 있습니다.

요약 화면에서는 현재 설정된

- 바닥재
- 벽지
- 가구
- 커튼

정보를 표 형태로 확인할 수 있습니다.

---

### 💾 7. 옵션 조합 저장 및 초기화

현재 선택한 인테리어 옵션 조합을 저장하고 다시 적용할 수 있습니다.

- 현재 선택 조합 저장
- 최대 3개의 조합 저장
- 저장된 조합 다시 적용
- 전체 옵션 기본값 복원
- 저장된 조합 초기화

현재 저장 기능은 **실행 중 메모리 기반 저장 방식**으로 구현되어 있습니다.
